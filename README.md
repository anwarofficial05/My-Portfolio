## 🛠️ Development & Deployment

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production (outputs static files to dist/)
npm run build

# 4. Preview production build locally
npm run preview
```

### One-Click Deployment to Netlify / Vercel
- **Netlify**: Drag & drop the `dist/` folder into Netlify Drop, or connect your GitHub repository and set build command to `npm run build` and publish directory to `dist`.
- **Vercel**: Import repository on Vercel with standard Vite framework preset.
